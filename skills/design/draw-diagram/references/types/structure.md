# type: 구조도

## 속성

- 답하는 질문: 무엇이 무엇으로 이루어지나
- 예: 모델 아키텍처, 블록 내부, 인코더·디코더 구성
- 흐름 방향: 기본 왼쪽 → 오른쪽. 블록을 깊게 쌓는 구조는 아래 → 위

## 규칙

화살표
- 화살표 = 데이터(텐서) 흐름만
- 라벨 없음. 꼭 필요하면 기호만 (`z_t`, `E`). shape는 본문이나 캡션에

포함과 반복
- 포함 관계는 컨테이너 중첩. 2단계까지
- 더 깊으면 확대 패널로 분리하고 확대선으로 원래 위치와 연결
- 반복해서 쌓는 블록은 `N×` 컨테이너로 묶거나 대표 몇 개만
- 한 패널 = 한 추상화 수준. 상세 패널과 개요 패널을 나란히

색과 모양
- 색 = 모듈 종류 (attention, MLP·Linear, conditioning 등)
- frozen은 회색 채움. 필요하면 `(Frozen)` 한 단어 추가 허용
- 차원을 줄이는 층(encoder, FC, projection)은 사다리꼴. 좁아지는 쪽이 출력
- 연산(`+`, `×`, concat)은 작은 원 안의 기호

입출력
- 입출력은 양 끝
- 아래에 기호 한 줄 + 이름 한 줄. 여러 입출력이면 두 기준선에 맞춰 정렬
- 조건 입력(timestep, text, audio)은 칩·원·아이콘으로 해당 블록 옆에 꽂음

배치
- 대칭 구조는 대칭으로 배치. 경로 차이는 색 순서로 보여줌
- residual·skip은 박스를 감싸는 직각 우회선

## 점검

- 화살표 라벨이 기호 말고 남아 있지 않은지
- 중첩이 2단계를 넘지 않는지
- 같은 종류 모듈이 같은 색·같은 크기인지
- 확대 패널과 원래 위치가 확대선으로 이어졌는지
