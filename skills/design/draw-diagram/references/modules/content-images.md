# 모듈: 내용물 그림

다이어그램 안에 들어가는 데이터 그림(스켈레톤, 파형, 지도, 이미지 썸네일)을 만든다.

## 원칙

- 데이터는 가능하면 실제 샘플에서 그림. 지어낸 값으로 그럴듯하게 만들지 않음
- 실제 샘플을 구할 수 없으면 사용자에게 알리고, 단순한 도식(막대 인형, 사인파)으로 대신하고 그 사실을 전달할 때 밝힘

## 작성 규칙

- matplotlib로 렌더링. 축, 눈금, 제목, 격자 없음 (`ax.axis('off')`)
- 배경 투명 (`transparent=True`). TikZ용은 PDF, SVG용은 PNG 300dpi
- 같은 대상이 여러 번 나오면 같은 크기·같은 시점·같은 색 설정
- 데이터 색은 다이어그램 팔레트와 겹치지 않게
- 시간 축은 앞뒤 프레임을 반투명 잔상으로 겹쳐서
- 데이터 변화(노이즈, 마스킹)는 같은 샘플을 변형해서 그림. 다른 샘플을 쓰지 않음
- 이미지 썸네일은 원본 비율 유지, 같은 높이로 맞춤

## 점검

- 이미지만 따로 열어서 봄. 잘림, 빈 여백 과다, 축 잔재가 없는지
- 다이어그램에 넣은 뒤 다시 봄. 너무 작아서 형태가 안 보이지 않는지
