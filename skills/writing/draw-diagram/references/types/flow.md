# type: 흐름도

## 속성

- 답하는 질문: 어떤 순서로 무엇이 일어나나
- 예: 학습 단계(pretrain/finetune), 데이터 전처리, 샘플링 절차, 에이전트 제어 흐름
- 흐름 방향: 기본 왼쪽 → 오른쪽

## 규칙

노드
- 노드 = 단계·상태. 이름은 명사 (`Determine Current Region` → `Region Estimation`)
- 모델은 블랙박스 하나. 내부 구조는 별도 구조도로
- 데이터 변화(corruption, 노이즈, 예측)는 내용물 그림의 차이로 보여줌

화살표
- 제어 흐름은 실선, 데이터 참조(메모리 읽기 등)는 점선
- 점선 색 = 출발한 곳의 색. 색으로 출처가 보이면 점선에 이름을 달지 않음
- 화살표 라벨은 화살표가 곧 연산(`Mask`, `Noise`)이거나 분기 이름일 때만. 같은 이름은 한 번만
- 갈라지는 화살표 여러 개는 그룹 라벨 하나로 묶을 수 있음 (`Downstream Tasks`)

분기와 반복
- 분기 = 마름모. 라벨은 짧게 (`Yes`/`No`)
- 반복은 루프 화살표로 실제로 그림. 글자로만 암시하지 않음
- 반복이 길면 첫 단계와 끝 단계만 그리고 사이를 점선으로 생략
- 1회성 구역과 반복 구역은 경계 테두리로 구분

단계와 정렬
- 단계(phase)가 여럿이면 줄로 나누고, 줄마다 단계 이름 하나
- 줄 사이에서 같은 역할의 요소는 같은 열에 정렬
- 같은 단계가 반복되면 입력의 순서·위치를 같게

변수
- 여러 곳에 들어가는 변수는 색 칩 (글자 기호 + 색)
- 칩의 뜻은 캡션에서 정의. 범례 없음

## 점검

- 노드 이름에 동사구가 없는지
- 반복이 루프 화살표나 점선 생략으로 그려졌는지
- 실선과 점선이 각각 한 가지 뜻만 갖는지
- 여러 줄일 때 같은 역할이 같은 열에 있는지
- 화살표 라벨이 연산·분기 이름 말고 남아 있지 않은지
