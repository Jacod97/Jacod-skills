# 팔레트

연한 채움색. 그림마다 종류에 하나씩 배정하고, 배정은 요소표에 적는다. 어떤 색을 어떤 종류에 줄지는 그림마다 정한다.

| 이름 | HEX |
|---|---|
| dgBlue | #BFDFFB |
| dgOrange | #FBD2B4 |
| dgMint | #C7F5EC |
| dgPurple | #DCD3F9 |
| dgYellow | #FBEBB4 |
| dgGreen | #D3EDC8 |
| dgPink | #F9D1F0 |
| dgGray | #D9D9D9 |
| dgPanel | #F2F2F2 |
| dgLine | #404040 |

- dgGray는 frozen·비활성, dgPanel은 컨테이너 배경, dgLine은 선·글자 전용
- 한 그림에 채움색은 4~5개 이내
- 같은 문서의 여러 그림은 같은 배정을 유지
- TikZ는 `assets/tikz-styles.tex`, SVG는 같은 HEX를 씀
