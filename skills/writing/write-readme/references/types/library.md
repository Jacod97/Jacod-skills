# 유형: 라이브러리·SDK·CLI

## 속성

- 대상: pip·npm 패키지, 프로그래밍 SDK, 재사용 모듈, 명령줄 도구.
- 독자 요구: 도구를 연동하거나 호출하는 방법 파악.

## 모듈

- 이미지가 제공되었거나 그림이 이해를 돕는 경우: `../modules/figures.md`.

## 권장 구성

1. 개요: 범위와 핵심 이점.
2. 설치: 확인된 패키지·소스 설치 명령과 사전 조건.
3. 빠른 시작: 완결되고 실행 가능한 최소 예제.
4. 기능: 지원 작업과 범위.
5. 사용법: 입력과 관찰 가능한 출력을 포함한 주요 사용 사례.
6. 공개 API 또는 명령: 직접 사용하는 함수, 클래스, 플래그 또는 옵션만 포함.
7. 호환성과 추가 예제: 필요한 경우 포함.

## 규칙

- 빠른 시작은 짧지만 완결되게 쓴다. 가져오기, 초기화와 대표 호출·명령을 포함한다.
- 공개 API 식별자는 독자가 사용해야 하므로 포함할 수 있다. 비공개 구현 식별자와 구분한다.
- 안전한 사용에 필요한 옵션 의미, 반환 형태, 오류 조건과 필수 설정을 설명한다.
- 별도 요청이 없으면 내부 알고리즘, 비공개 메서드, 자료 구조와 모듈 호출 관계를 설명하지 않는다.
- API 시그니처나 예상 출력을 지어내지 않는다. 공개 정의·예제로 검증하거나 불확실성을 밝힌다.

## 점검

- 빠른 시작 예제가 완결되고 공개 인터페이스와 일치하는지 확인한다.
- API 이름, 플래그와 출력 예제에 근거가 있는지 확인한다.
