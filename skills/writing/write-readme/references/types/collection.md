# 유형: 자료·스킬 모음

## 속성

- 대상: 에이전트 스킬, 템플릿, 선별된 참고 자료, 추천 자료 목록, 에셋 모음.
- 독자 요구: 제공 자료의 종류, 적합한 자료를 찾는 방법과 사용 방법 파악.

## 모듈

- 이미지가 제공되었거나 그림이 이해를 돕는 경우: `../modules/figures.md`.

## 권장 구성

1. 개요: 모음의 목적과 범위.
2. 목록: 각 항목의 간결한 목적과 링크.
3. 분류: 탐색에 도움이 되는 경우 용도별로 구성.
4. 시작하기: 공통 준비, 선택과 사용 방법.
5. 요구 사항: 해당하는 플랫폼·도구 제약.
6. 기여와 라이선스: 실제로 정해진 경우에만 포함.

## 규칙

- 각 항목의 이름, 수행 목적과 해당 위치의 링크를 제공한다. 내부 구현 설명은 피한다.
- 항목이 많으면 모든 항목을 길게 설명하기보다 탐색하기 쉬운 표나 분류된 목록을 사용한다.
- 공통 설치 방법은 한 번만 설명하고, 자료별 예외 요구 사항을 표시한다.
- 연결한 항목과 분류 이름이 실제로 존재하는지 확인한다.
- 간단한 분류 목록으로 충분하면 아키텍처 그림을 추가하지 않는다.

## 점검

- 목록의 링크와 분류 이름이 유효한지 확인한다.
- 공통 준비 절차를 한 번만 설명하고 예외 요구 사항을 표시했는지 확인한다.
