# 유형: 연구·실험

## 속성

- 대상: 논문 구현, AI 모델 학습, 시뮬레이션, 실험 저장소.
- 독자 요구: 연구 문제, 핵심 아이디어와 실험 재현 방법 파악.

## 모듈

- 이미지가 제공되었거나 그림이 이해를 돕는 경우: `../modules/figures.md`.

## 권장 구성

1. 개요: 문제와 연구 목표.
2. 방법: 이해하기 쉬운 개념 설명과 선행 연구 대비 실제 차별점.
3. 요구 사항: 검증되었거나 명확히 명시된 환경과 연산 자원 조건.
4. 데이터: 데이터셋, 출처, 라이선스와 전처리 방법.
5. 학습: 재현 가능한 학습 명령과 관련 설정.
6. 평가: 평가 절차, 체크포인트, 지표와 명령.
7. 결과: 실험 조건과 실제 관측값만 포함. 실행 전이면 생략.
8. 인용: 발표되었거나 제공된 경우 검증된 논문과 서지 정보.

## 규칙

- 독자적인 기여, 재사용한 기준 모델과 향후 제안을 명확히 구분한다.
- 구현 내부보다 재현에 필요한 정보를 우선한다.
- 방법은 개념 수준에서 설명한다. 자세한 유도는 기존 논문이나 부록이 있으면 연결하되, 추가 문서 생성을 강제하지 않는다.
- 검증된 테스트와 계획한 테스트를 구분한다. 성능, 학습 자원 또는 발표 논문을 지어내지 않는다.

## 점검

- 재현 명령, 데이터 요구 사항과 실험 조건이 명확한지 확인한다.
- 결과와 인용을 검증하고 제안 사항을 구분했는지 확인한다.
