# 읽는 방식 규칙

type 파일의 "읽는 방식" 속성에 해당하는 절만 적용한다.

## 참조형
사용: 연구일지, 참조 문서

- 독자는 필요한 절만 찾아 읽는다.
- 같은 수준의 항목은 같은 구조와 순서로 쓴다. 예: 데이터셋마다 데이터 구성 → 클래스 → 관절/필드 구성 → 데이터 형태 → 특이사항
- 주의사항은 대상마다 두고, 문서 끝에 모은 "주의사항" 장을 만들지 않는다.

## 선형
사용: 리뷰, 연구계획서

- 독자는 처음부터 끝까지 순서대로 읽는다.
- 앞뒤가 이유로 이어져야 한다. 다음 단계로 넘어갈 때 앞 단계와의 연결을 한 문장으로 잇는다.
- 전체 흐름(데이터 흐름 또는 논증 흐름)을 먼저 보여주고 세부를 뒤에 둔다.

번호 참조를 쓸지, 같은 기호를 다시 설명할지는 읽는 방식이 아니라 독자(학습자/심사자)에 따라 갈리므로 type이 정한다.
