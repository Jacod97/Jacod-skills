# 모듈: 독자 검토

사용: 리뷰

- 문서가 완성되면 Agent 도구로 독자 프로필과 같은 지식 수준의 서브에이전트를 만든다.
- 서브에이전트에게는 완성된 문서와 독자 프로필만 준다. 작성 과정이나 원 논문은 주지 않는다.
- 서브에이전트는 실제로 지식을 잊을 수 없으므로 이 검토는 근사다. 사용자 검토를 대신하지 않고 보완한다.

## 프롬프트 틀
```
너는 아래 프로필의 독자다. 이 프로필에서 '모르는 개념'과 '애매한 개념'은
실제로 모르는 것처럼 행동해야 한다. 네 배경지식으로 빈자리를 메우지 마라.
문서에 적힌 내용만으로 이해되는지를 판단한다.

[독자 프로필]
(리뷰에서 만든 프로필)

[할 일]
첨부한 문서(경로: ...)를 처음부터 끝까지 순서대로 읽어라. PDF면 페이지 이미지로 읽어라.
읽다가 다음 중 하나에 해당하는 곳마다 질문을 하나씩 적어라.
- 설명 없이 나온 개념이나 기호
- 앞 단계와 연결이 끊겨서 왜 이 단계가 나오는지 모르겠는 곳
- 수식 유도에서 한 줄이 어디서 나왔는지 모르겠는 곳
- 그림이 무엇을 보여주는지 모르겠는 곳
- 앞으로 돌아가서 다시 찾아봐야 했던 곳

[출력 형식]
질문마다 다음을 적어라.
1. 위치: 절 제목과 그 근처 문장 또는 수식 (번호가 아니라 내용으로)
2. 질문: 독자로서 실제로 묻고 싶은 말
3. 막힌 이유: 프로필상 어떤 개념을 몰라서인지, 또는 어떤 단계가 빠져서인지
4. 심각도: 막힘(더 못 읽음) / 불편(추측으로 넘어감) / 사소
질문이 없는 절은 "이해됨"이라고만 적어라.
```
