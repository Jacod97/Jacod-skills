# 모듈: 참고문헌

사용: 연구계획서, 리뷰(인용이 있을 때)

- 실제로 확인한 문헌만 넣는다. 확인할 수 없으면 그 사실을 밝히고 항목을 만들지 않는다.
- 1차 문헌(원 논문, 공식 저장소, 표준)을 우선한다.
- 인용 형식은 문서 안에서 일관되게 쓴다. 기본은 번호식 [1].
- LaTeX에서는 `thebibliography` 또는 BibLaTeX를 쓰고, 컴파일 때 BibTeX/Biber를 함께 돌린다.

## 점검
- [ ] 본문의 모든 인용이 참고문헌에 있고, 참고문헌의 모든 항목이 본문에서 인용됨
- [ ] 모든 항목을 실제로 확인함 (저자, 연도, 제목, 출처)
