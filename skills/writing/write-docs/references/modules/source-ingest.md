# 모듈: 원자료 수집

사용: 리뷰, 참조 문서, 연구계획서

## 사용자 자료가 있을 때 (최우선)
- 사용자가 올린 자료를 주재료로 쓴다. PDF가 있으면 웹에서 같은 논문을 따로 찾지 않는다.
- PDF는 부록까지 전부 읽는다. 구현 상세(네트워크 구조, 하이퍼파라미터, 유도)는 보통 부록에 있다.
  - 텍스트는 pdftotext/pdfplumber로 뽑는다. 수식·그림이 있는 쪽은 pdftoppm으로 렌더링해 눈으로 확인한다 (추출 텍스트의 수식은 깨지기 쉬움).
  - 그림 목록을 만든다: 그림 번호, 캡션, 쪽, 설명하는 개념
  - 실험 표와 하이퍼파라미터 값은 PDF에서 직접 가져오고, 어느 표·절에서 왔는지 남긴다.
  - 핵심 식은 논문 식과 대조해 원문 위치를 밝힌다 ("논문의 식 (1)").

## 데이터셋·저장소
- 공식 저장소, 논문, README, 실제 데이터 파일을 직접 확인한다. 받을 수 있으면 반드시 받아 실제 값을 뽑는다.

## 사용자 자료가 없을 때
- WebSearch/WebFetch로 읽는다 (arXiv는 `arxiv.org/html/<id>`로 본문과 캡션을 읽을 수 있음).
- 논문이 아닌 개념이면 표준 교과서·강의자료·원 논문을 찾아 읽는다.
- 셸에서 외부 사이트 다운로드는 대부분 막혀 있다. 거부되면 다른 명령으로 우회하지 않는다.
- 원 그림이나 파일이 꼭 필요하면 사용자에게 PDF나 파일 하나를 요청한다 (그림을 한 장씩 요청하지 않음). 기다리는 동안 할 수 있는 작업은 먼저 한다.
