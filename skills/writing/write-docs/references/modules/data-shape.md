# 모듈: 데이터 형태

사용: 참조 문서, 연구일지(데이터 파일을 다룰 때)

- 데이터나 파일을 다루면 불러오는 코드와 출력 형태를 함께 보인다. 몇 줄로 끝나므로 생략하지 않는다.
- 배열·딕셔너리·JSON: 코드 블록 안에 주석으로 shape, 자료형, 실제 값을 적는다.
  ```python
  data = np.load("humanact12/P01G01R01F0001T0064A0101.npy")
  data.shape     # (64, 24, 3)   프레임 × 관절 × xyz
  data.dtype     # float64
  ```
- CSV·표 형식: `pd.read_csv` 코드를 보이고, 결과 앞 몇 행을 표로 넣는다.
- 텍스트 파일: 한 줄을 읽고 구분자로 나눈 결과를 주석으로 각 부분의 의미와 함께 보인다.
- 실제 파일을 받을 수 있으면 반드시 실제 값으로 실행한다. 받을 수 없으면 공식 형식의 키 구조와 shape만 주석으로 적고, 실제 값이 아님을 본문에 밝힌다.

## 점검
- [ ] 데이터마다 불러오는 코드와 출력 형태가 있음
- [ ] 실제 값이 아닌 예시는 본문에 그 사실을 밝힘
