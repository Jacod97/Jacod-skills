# 모듈: 템플릿 사용

사용: 연구일지, 연구계획서 (LaTeX 출력 모듈의 시작 파일에도 같은 방식 적용)

- 템플릿 원본(`assets/` 안의 파일)은 수정하지 않는다. 작업 폴더로 복사해 복사본만 고친다.
- 자리표시 문구("제목", "본문 단락", "TODO", `<문서 제목>`, "계열 A", 예시 숫자 등)는 전부 실제 내용으로 바꾼다.
- 쓰지 않는 예시 요소는 지운다. 예시 데이터를 실제 결과처럼 남기지 않는다.

## 점검
- [ ] 원본 템플릿이 바뀌지 않음
- [ ] 자리표시 문구와 예시 데이터가 남아 있지 않음
