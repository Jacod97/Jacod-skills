# 모듈: 그림 제작

사용: 리뷰 (다른 type도 필요하면 사용)

## 원 논문 그림
- 원 그림을 쓸지는 직접 판단한다. 개념을 가장 잘 보여주는 원 그림이 있으면 그 설명 위치에 넣는다.
- 캡션에 출처(저자, 연도, Fig. 번호)를 적고, 그림 속 표시가 무엇인지 캡션과 본문에서 풀어 준다.
- 해당 쪽을 200~300dpi로 렌더링해 그림 영역만 잘라 쓴다. 래스터 그림은 pdfimages로 원본 추출도 시도한다.
- 잘라낸 그림을 열어 캡션이나 다른 그림이 섞이지 않았는지 확인한다.

## 직접 만드는 그림
- matplotlib: 함수 그래프, 분포, 수치 예시. 수식은 mathtext(`$w_i$`, `$\hat{C}$`)
- OpenCV: 실제 이미지에 격자·픽셀 값·표시를 얹어 설명
- 예시 사진: scikit-image 예제 이미지처럼 로컬에서 쓸 수 있는 것 우선. 웹 이미지 다운로드가 막히면 다른 수단으로 대체한다.

## 전체 구조 그림
- 모듈 다이어그램으로 그린다: 색으로 구분한 모듈 상자, 흐름 화살표, 모듈 사이를 오가는 값의 기호 태그와 그 범례.
- 다음 모듈로 넘어가는 데이터 흐름은 실선, 다른 단계로 건너가는 정보(되먹임, 정답, 역전파)는 점선.
- 수식이 들어가면 TikZ로 그려 본문과 같은 글꼴을 쓴다.

## 점검
- [ ] 그림 안 수식이 본문과 같은 표기 (코드식 표기 없음)
- [ ] 렌더링해 글자 겹침, 잘림, 깨진 글리프 없음
- [ ] 원 그림마다 출처가 캡션에 있음
