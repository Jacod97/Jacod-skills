# type: 참조 문서

대상(데이터셋, 라이브러리, 코드베이스, 도구)을 조사해 나중에 찾아보는 정리 문서를 만든다.

## 속성
- 읽는 방식: 참조형
- 출력: LaTeX 기본 서식. PDF와 .tex를 함께 전달.
- 합의: core 구성안 협의 (추가 단계 없음)
- 모듈: `modules/source-ingest.md`, `modules/latex.md`, `modules/data-shape.md`
- 진술의 지위: 확인된 사실만 쓴다. 추측("~결함이 있을 수 있다"), 권고("~를 쓰는 것이 좋다"), 해석("출력에서 읽을 수 있는 것")을 쓰지 않는다. 관찰에서 나오는 판단은 사용자가 직접 넣는다.
- 정의 범위: 처음 나오는 모든 전문 용어·약어·모델명

## 합의
- core 구성안 협의를 따른다. 원자료를 확인한 뒤 구성안을 제안한다. 포함 관계(원본 → 가공)와 대상마다 같은 소절 순서가 구성안에 드러나야 한다.

## 고유 규칙
- 제목 아래에는 작성일과 기준(출처) 한 줄만 두고 바로 1장을 시작한다. 부제목을 쓰지 않는다.
- 참고 링크 장과 부록은 사용자가 요청할 때만 넣는다.
- 포함 관계는 장·절 계층으로 표현한다. 예: 가공 데이터셋이 원본 데이터셋으로 만들어지면, 원본들을 한 장 아래 절로 묶고 가공 데이터셋을 다음 장으로 둔다.
- 장 구성은 문서마다 다르다. 위는 원칙이고 고정 목차가 아니다.
- 전문 용어는 처음 나오는 문단 바로 아래 `terms` 환경(※ 용어 설명)으로 정의한다. 그림 안 라벨처럼 정의를 달 수 없는 곳에서 먼저 나오면 일반 표현으로 바꾸고, 정의는 본문으로 미룬다.

## 점검
- [ ] 제목 아래 작성일·기준 한 줄만 있음
- [ ] 처음 나오는 전문 용어마다 ※ 용어 설명이 있음
- [ ] 데이터마다 불러오는 코드와 출력 형태가 있음
- [ ] 특이사항에 추측, 권고, 해석이 없음
