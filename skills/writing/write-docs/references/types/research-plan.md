# type: 연구계획서

완성된 논문을 지어내는 것이 아니라, 학술적으로 믿을 수 있는 연구 계획을 만든다.

## 속성
- 읽는 방식: 선형
- 출력: LaTeX 학술 변형 (`assets/latex/academic.tex`). .tex와 .pdf를 함께 전달. Word, HTML, Markdown PDF로 대체하지 않는다.
- 합의: core 구성안 협의 + 빠진 선택
- 모듈: `modules/source-ingest.md`, `modules/latex.md`, `modules/template.md`, `modules/bibliography.md`
- 진술의 지위: 확립된 사실 / 가정 / 가설 / 제안한 구현 / 미검증 주장을 명시적으로 구분한다. 제안한 이점을 관찰 결과처럼 쓰지 않는다.
- 정의 범위: 중요한 기호와 개념은 처음 쓸 때 한 번 정의하고, 이후에는 참조한다.
- 초록: 쓴다 (core의 요약 상자 금지와 별개).

## 합의: core 구성안 협의 + 빠진 선택
- core 구성안 협의를 따르고, 구성안과 함께 아직 정해지지 않은 선택(주제 범위, 독자·제출처, 연구 성숙도, 언어, 분량, 필수 절)을 보여준다. 각 선택에는 에이전트의 제안값을 붙인다.
- 승인 전에는 파일을 만들지 않는다.

## 구조 (고정 목차가 아니라 절이 맡는 역할)
1. 제목과 메타데이터: 주제와 방법이 드러나는 제목. 저자·기관·날짜는 알 때만
2. 초록: 문제, 공백, 제안, 검증 방법, 조건부 기대 기여. 결과를 가정하지 않음
3. 서론: 동기, 구체적 문제, 필요성, 범위
4. 관련 연구: 확인한 선행 연구, 적용 가능성, 남은 공백. 근거 없는 novelty 주장 금지
5. 연구 질문·가설: 명시적이고 반증 가능하게. 과학적·이론적·공학적 목표 구분
6. 제안 방법
7. 평가
8. 구현 계획 (선택): 마일스톤, 의존성, 자원, 결정 지점. 사용자 마감일을 지어내지 않음
9. 기대 기여: 구체적이고 조건부로
10. 위험과 한계: 타당성 위협, 일반화, 식별 가능성, 자원 제약, 대안, 부정적 결과의 해석
11. 참고문헌: 참고문헌 모듈

- 짧은 계획서는 관련 연구를 서론에 합친다. 이론 중심이면 증명을, 공학 중심이면 구조와 통합을, 실험 중심이면 데이터와 실험 설계를 앞세운다.
- 문제 → 선행 연구와 공백 → 질문·가설 → 제안 방법 → 검증 → 기여·한계로 논증이 이어져야 한다. 목표 → 메커니즘 → 조작적 검증 → 기여가 서로 맞는지 확인한다.

## 제안 방법
- 가정, 기호, 차원, 입출력, 핵심 식, 인터페이스, 의존성, 구현 가능성을 구체적으로 쓴다. 잠정적인 선택은 잠정적이라고 밝힌다.
- 제안한 메커니즘이 왜 공백을 해결하는지 쓴다. 동기는 증명이 아니다.
- 정확한 유도, 근사, 미분 가능한 대리 함수, 경험적 주장을 구분한다. 빌려 온 식은 인용한다.
- ML 시스템이면 학습 시와 추론 시 쓸 수 있는 입력, frozen/trainable 구성 요소, gradient 경로, 표현 호환성을 적는다.
- 외부 코드·모델의 인터페이스는 확인해서 쓰고, API 기능을 지어내지 않는다.

## 평가
- 연구 질문마다 실험, 측정 가능한 지표, 또는 엄밀한 이론적 논증을 연결한다.
- 데이터셋의 출처·라이선스·split, 공정한 baseline, 통제된 ablation을 정한다. split, 전처리, 평가 프로토콜을 맞춘다.
- 지표를 조작적으로 정의한다: 집계 방식, 단위, 좋아지는 방향. 학습 loss만을 성공 근거로 쓰지 않는다.
- leakage, 분포 변화, seed, 분산, 계산 예산, 소프트웨어 버전, checkpoint를 필요한 만큼 다룬다.
- 코드 정확성 테스트와 모델 성능 테스트를 분리하고, sanity test와 예상 실패 원인을 넣는다.
- null result를 어떻게 해석할지, 가설이 틀린 경우와 구현이 깨진 경우를 어떻게 구분할지 쓴다.

## 전달
- 완성한 연구 설계와, 아직 남은 검증 항목을 짧게 요약한다.

## 점검
- [ ] 사실·가정·가설·제안·미검증 주장이 구분됨
- [ ] 연구 질문마다 실험·지표 또는 이론적 논증이 연결됨
- [ ] 결과, 참고문헌, 마감일을 지어내지 않음
- [ ] 초록에 결과를 가정한 문장이 없음
