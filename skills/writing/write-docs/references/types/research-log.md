# type: 연구일지

## 속성
- 읽는 방식: 참조형
- 출력: HTML 템플릿. 디자인을 새로 만들지 않는다.
- 합의: core 구성안 협의 (추가 단계 없음)
- 모듈: `modules/template.md`, `modules/html-template.md`, `modules/data-shape.md`(데이터 파일을 다룰 때)
- 진술의 지위: 사실과 해석을 분리해서 쓰고, 해석은 허용한다. 모르면 "미확인".

## 합의
- core 구성안 협의를 따른다. 사용자가 준 재료로 기록할 절과 각 절에 들어갈 내용, 절 사이 흐름을 제안하고 승인받는다.

## 작성
1. HTML 템플릿을 템플릿 사용 모듈 방식으로 복사한다. 파일 이름은 `YYYY-MM-DD_주제.html`.
2. 복사본의 `<main>` 안쪽만 실제 내용으로 채운다.
3. 쓰지 않는 요소(예시 그림, 예시 차트, 수식, 각주 등)는 지운다.

## 고유 규칙
- 부제목(`p.subtitle`)을 쓸 수 있다.
- byline은 `<span>날짜</span><span>작성자</span><span>과제명 또는 실험 번호</span>` 순서. 모르는 항목은 지운다.
- `<strong>`은 문단당 1회, 문서 전체 5회 이내.
- 소제목을 영어로만 쓰지 않는다. 템플릿의 "Title 제목", "Heading 대제목" 같은 자리표시는 실제 한국어 제목으로 바꾼다.
- 관찰한 사실과 해석을 같은 문장에 섞지 않는다.

## 점검
- [ ] 파일 이름이 `YYYY-MM-DD_주제.html`
- [ ] `<strong>` 문단당 1회, 전체 5회 이내
- [ ] 영어로만 된 소제목 없음
- [ ] HTML 템플릿 모듈 점검 통과
