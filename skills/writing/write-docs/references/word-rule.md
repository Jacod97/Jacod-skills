# 문서 표기 규칙

모든 문서에 적용한다. core.md의 문체 규칙 중 용어 표기와 개조식 종결은 이 파일이 기준이다.

## 1. 영어 발음을 한글로 옮긴 표기 사용 금지

영어 용어를 한글 발음으로 옮겨 쓰지 않고 영어 원문으로 작성한다. 한글 발음과 영어를 병기하는 방식도 사용하지 않는다.

단, 원본 데이터의 컬럼명·값·고유 명칭을 인용할 때는 원문을 그대로 유지한다. 이 규칙을 적용하기 위해 원본 데이터를 수정하거나 원본 명칭을 번역·치환하지 않는다.

사용자가 지정한 문서 제목과 이름도 원문을 유지한다. 제목에 한글 발음 표기가 있어도 고치지 않는다.

- 수정 전: 코사인 유사도(Cosine similarity)
- 수정 후: Cosine similarity

### 예외 목록

다음 단어는 한글 표기를 허용한다.

- 이미지
- 데이터
- 텍스트
- 데이터셋
- 파일

## 2. 영문 명사와 한글 명사를 섞은 표현 자제

하나의 개념을 나타내는 복합 명사는 영어와 한글을 어색하게 섞어 쓰지 않는다. 영어 전문 용어는 완결된 영어 표현으로 쓰고, 한글 표기를 허용한 용어는 자연스러운 한글 표현으로 통일한다. 영어 단어의 일부만 한글로 바꾸는 표기도 사용하지 않는다.

- Cosine 유사도 → Cosine similarity
- 데이터set → 데이터셋
- 평가 Dataset → 평가 데이터셋

## 3. 개조식은 명사형 또는 '~함'으로 끝맺기

개조식은 명사형 또는 '~함' 음슴체로 끝맺는다. 개조식에서 '~다', '~습니다' 같은 서술형 종결은 쓰지 않는다.

- Embedding했다 → Embedding 또는 Embedding함
- 연결합니다 → 연결 또는 연결함
